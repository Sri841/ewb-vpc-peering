    Why it behaves this way

    • Active peering is not enough. Packets need routes on both sides, and security groups must allow them.
    • Return route: without 10.10.0.0/16 → pcx in VPC B, replies are dropped.
    • ProxyJump: the bastion opens the connection to App-B, so the public subnet needs the peering route too.
    • Security groups vs routes: removing the ICMP rule stops ping but the dashboard (TCP 9000) keeps working.
